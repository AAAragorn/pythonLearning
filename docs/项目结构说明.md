## 核心目录说明

### 1. app/ - 应用核心

#### `app/__init__.py` - 应用工厂

```python
from flask import Flask
from .config import Config

def create_app(config_class=Config):
    """应用工厂函数，用于创建和配置 Flask 应用实例"""
    app = Flask(__name__)
    app.config.from_object(config_class)
    
    # 注册蓝图
    from app.routes import main
    app.register_blueprint(main)
    
    # 初始化扩展
    # db.init_app(app)
    # migrate.init_app(app, db)
    
    return app
```

**优势**:
- 便于测试（可以创建不同配置的应用实例）
- 支持多环境配置
- 延迟初始化扩展

#### `app/config.py` - 配置管理

```python
import os
from dotenv import load_dotenv

load_dotenv()

class Config:
    """基础配置"""
    SECRET_KEY = os.environ.get('SECRET_KEY')
    SQLALCHEMY_DATABASE_URI = os.environ.get('DATABASE_URL')
    
class DevelopmentConfig(Config):
    """开发环境配置"""
    DEBUG = True
    
class ProductionConfig(Config):
    """生产环境配置"""
    DEBUG = False
```

**配置分离**:
- 敏感信息通过环境变量管理
- 不同环境使用不同配置类
- 配置继承减少重复

#### `app/routes.py` - 路由定义

```python
from flask import Blueprint, jsonify

main = Blueprint('main', __name__)

@main.route('/')
def index():
    return jsonify({'message': 'Hello World'})
```

**蓝图优势**:
- 模块化路由管理
- 便于组织大型应用
- 支持路由前缀

### 2. tests/ - 测试目录

#### `tests/conftest.py` - Pytest 配置

```python
import pytest
from app import create_app

@pytest.fixture
def app():
    """创建测试应用"""
    app = create_app(TestConfig)
    return app

@pytest.fixture
def client(app):
    """创建测试客户端"""
    return app.test_client()
```

**测试组织**:
- 单元测试：测试单个函数/方法
- 集成测试：测试模块间交互
- 功能测试：测试完整功能流程

### 3. scripts/ - 运维脚本

#### 脚本类型

| 脚本 | 用途 | 运行时机 |
|------|------|---------|
| `setup-server.sh` | 初始化服务器 | 首次部署前 |
| `deploy.sh` | 部署应用 | 每次发布 |
| `backup.sh` | 数据备份 | 定期执行 |
| `test.sh` | 运行测试 | CI/CD 流程 |
| `local-dev.sh` | 本地开发环境 | 开发启动 |

### 4. nginx/ - Web 服务器配置

#### `nginx.conf` 配置说明

```nginx
upstream app_server {
    # 负载均衡配置
    server web:5000;
}

server {
    listen 80;
    
    location / {
        proxy_pass http://app_server;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
    
    location /static {
        alias /app/static;
        expires 30d;
    }
}
```

**关键配置**:
- 反向代理到应用服务器
- 静态文件直接提供
- 请求头转发
- 缓存控制

### 5. .github/workflows/ - CI/CD

#### CI 流程 (`ci.yml`)

```yaml
name: CI
on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Run tests
        run: pytest tests/
```

#### CD 流程 (`cd.yml`)

```yaml
name: CD
on:
  push:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Deploy to server
        run: ./scripts/deploy.sh
```

### 4. Dockerfile

**多阶段构建示例**：

```dockerfile
# 构建阶段
FROM python:3.11-slim as builder
WORKDIR /app
COPY requirements.txt .
RUN pip install --user -r requirements.txt

# 运行阶段
FROM python:3.11-slim
WORKDIR /app
COPY --from=builder /root/.local /root/.local
COPY . .
ENV PATH=/root/.local/bin:$PATH
CMD ["gunicorn", "-b", "0.0.0.0:5000", "wsgi:app"]
```

app = create_app()

from app import create_app

app = create_app()

if __name__ == "__main__":

## 最佳实践

### 1. 代码组织

- **按功能模块组织**：将相关代码放在一起
- **保持文件简短**：单个文件不超过 500 行
- **使用蓝图**：大型应用按功能划分蓝图

### 2. 配置管理

- **分离配置**：开发、测试、生产环境独立配置
- **环境变量**：敏感信息使用环境变量
- **配置验证**：启动时验证必需的配置

### 3. 依赖管理

- **固定版本**：生产环境使用确定版本
- **定期更新**：及时修复安全漏洞
- **最小化依赖**：只安装必需的包

### 4. 测试组织

- **测试覆盖率**：目标 80% 以上
- **快速测试**：单元测试应该快速运行
- **隔离测试**：测试之间相互独立

### 5. 文档维护

- **README**：项目概述和快速开始
- **DEPLOYMENT**：详细部署步骤
- **代码注释**：解释为什么而不是做什么
- **API 文档**：接口说明和示例

## 扩展建议

### 添加数据库支持

```python
# app/__init__.py
from flask_sqlalchemy import SQLAlchemy
from flask_migrate import Migrate

db = SQLAlchemy()
migrate = Migrate()

def create_app(config_class=Config):
    app = Flask(__name__)
    app.config.from_object(config_class)
    
    db.init_app(app)
    migrate.init_app(app, db)
    
    return app
```

### 添加 API 文档

```python
# 使用 Flask-RESTX
from flask_restx import Api, Resource

api = Api(app, version='1.0', title='My API',
          description='API Documentation')

@api.route('/users')
class UserList(Resource):
    @api.doc('list_users')
    def get(self):
        """List all users"""
        return {'users': []}
```

### 添加认证授权

```python
# 使用 Flask-JWT-Extended
from flask_jwt_extended import JWTManager, jwt_required

jwt = JWTManager(app)

@app.route('/protected')
@jwt_required()
def protected():
    return {'message': 'This is protected'}
```
