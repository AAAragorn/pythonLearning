# 环境准备详细指南

## 1. 本地开发环境

### 1.1 Python 安装

#### macOS

```bash
# 使用 Homebrew 安装
brew install python@3.11

# 验证安装
python3 --version

# 配置别名（可选）
echo "alias python=python3" >> ~/.zshrc
echo "alias pip=pip3" >> ~/.zshrc
source ~/.zshrc
```

#### Ubuntu/Debian

```bash
# 更新包索引
sudo apt-get update

# 安装 Python 和相关工具
sudo apt-get install -y \
    python3.11 \
    python3.11-venv \
    python3-pip \
    python3.11-dev \
    build-essential

# 设置默认 Python 版本
sudo update-alternatives --install /usr/bin/python3 python3 /usr/bin/python3.11 1
```

#### Windows

1. 访问 [Python 官网](https://www.python.org/downloads/)
2. 下载 Python 3.11 安装程序
3. 运行安装程序，勾选 "Add Python to PATH"
4. 验证安装：
   ```powershell
   python --version
   pip --version
   ```

### 1.2 虚拟环境管理

#### 使用 venv（推荐）

```bash
# 创建虚拟环境
python3 -m venv venv

# 激活虚拟环境
# Linux/macOS
source venv/bin/activate

# Windows (PowerShell)
.\venv\Scripts\Activate.ps1

# Windows (CMD)
venv\Scripts\activate.bat

# 停用虚拟环境
deactivate
```

#### 使用 pyenv（多版本管理）

```bash
# 安装 pyenv
curl https://pyenv.run | bash

# 配置环境变量（添加到 ~/.bashrc 或 ~/.zshrc）
export PATH="$HOME/.pyenv/bin:$PATH"
eval "$(pyenv init -)"
eval "$(pyenv virtualenv-init -)"

# 安装 Python 版本
pyenv install 3.11.0

# 设置全局版本
pyenv global 3.11.0

# 创建虚拟环境
pyenv virtualenv 3.11.0 myproject
pyenv activate myproject
```

#### 使用 virtualenvwrapper

```bash
# 安装
pip install virtualenvwrapper

# 配置（添加到 ~/.bashrc）
export WORKON_HOME=$HOME/.virtualenvs
source /usr/local/bin/virtualenvwrapper.sh

# 创建环境
mkvirtualenv myproject

# 切换环境
workon myproject

# 列出所有环境
lsvirtualenv

# 删除环境
rmvirtualenv myproject
```

**配置步骤**:
1. File → Settings → Project → Python Interpreter
2. 添加虚拟环境: Add Interpreter → Virtualenv Environment

**推荐设置**:
- 启用 PEP 8 检查
- 配置代码格式化为 Black
- 启用类型检查
- 配置测试运行器为 pytest

### 1.4 Git 配置

```bash
# 设置用户信息

git config --global user.email "your.email@example.com"

# 设置默认分支名

```

```bash

curl https://raw.githubusercontent.com/github/gitignore/main/Python.gitignore -o .gitignore
```

## 2. 生产服务器环境

### 2.1 服务器选择

#### 云服务提供商对比

| 提供商 | 优势 | 适用场景 |
|--------|------|---------|
| AWS EC2 | 功能全面、生态完善 | 大型企业应用 |
| Google Cloud | 机器学习支持好 | AI/ML 项目 |
| Azure | 与微软生态集成好 | Windows 应用 |
| DigitalOcean | 简单易用、性价比高 | 中小型项目 |
| Linode | 性能稳定 | 传统 Web 应用 |
| 阿里云 | 国内访问快 | 中国市场应用 |

#### 推荐配置

**小型应用** (< 1000 DAU):
- 2 vCPU
- 2-4GB RAM
- 40GB SSD
- 成本: ~$10-20/月

**中型应用** (1000-10000 DAU):
- 4 vCPU
- 8GB RAM
- 80GB SSD
- 成本: ~$40-80/月

**大型应用** (> 10000 DAU):
- 8+ vCPU
- 16GB+ RAM
- 160GB+ SSD
- 负载均衡 + CDN
- 成本: $200+/月

### 2.2 服务器初始化

#### 创建并连接服务器

**AWS EC2 示例**:

```bash
# 连接到实例
ssh -i "your-key.pem" ubuntu@ec2-xx-xx-xx-xx.compute.amazonaws.com

# 首次连接后更新系统
sudo apt-get update
sudo apt-get upgrade -y
```

**DigitalOcean 示例**:

```bash
# 使用 SSH 密钥连接
ssh root@your-droplet-ip

# 创建新用户
adduser deploy
usermod -aG sudo deploy

# 切换到新用户
su - deploy
```

#### 配置 SSH 密钥认证

```bash
# 在本地生成密钥
ssh-keygen -t rsa -b 4096 -C "your_email@example.com"

# 复制公钥到服务器
ssh-copy-id deploy@your-server-ip

# 或手动复制
cat ~/.ssh/id_rsa.pub | ssh deploy@your-server-ip "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"

# 在服务器上设置权限
chmod 700 ~/.ssh
chmod 600 ~/.ssh/authorized_keys
```

#### 禁用密码认证（安全加固）

```bash
# 编辑 SSH 配置
sudo vim /etc/ssh/sshd_config

# 修改以下设置
PermitRootLogin no
PasswordAuthentication no
PubkeyAuthentication yes

# 重启 SSH 服务
sudo systemctl restart sshd
```

### 2.3 安装必要软件

#### 使用自动化脚本

```bash
# 下载并运行安装脚本
wget https://your-repo.com/scripts/setup-server.sh
chmod +x setup-server.sh
sudo ./setup-server.sh
```

#### 手动安装

**更新系统**:

```bash
sudo apt-get update
sudo apt-get upgrade -y
sudo apt-get autoremove -y
```

**安装基础工具**:

```bash
sudo apt-get install -y \
    curl \
    wget \
    git \
    vim \
    htop \
    tmux \
    unzip \
    build-essential \
    ca-certificates \
    gnupg \
    lsb-release
```

**安装 Docker**:

```bash
# 添加 Docker 官方 GPG 密钥
sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg

# 设置仓库
echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu \
  $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

# 安装 Docker Engine
sudo apt-get update
sudo apt-get install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

# 启动 Docker
sudo systemctl start docker
sudo systemctl enable docker

# 添加当前用户到 docker 组
sudo usermod -aG docker $USER
newgrp docker

# 验证安装
docker --version
docker compose version
```

**安装 Docker Compose（独立版本）**:

```bash
# 获取最新版本
DOCKER_COMPOSE_VERSION=$(curl -s https://api.github.com/repos/docker/compose/releases/latest | grep 'tag_name' | cut -d\" -f4)

# 下载
sudo curl -L "https://github.com/docker/compose/releases/download/${DOCKER_COMPOSE_VERSION}/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose

# 添加执行权限
sudo chmod +x /usr/local/bin/docker-compose

# 验证
docker-compose --version
```

### 2.4 防火墙配置

#### UFW（Uncomplicated Firewall）

```bash
# 启用 UFW
sudo ufw enable

# 设置默认策略
sudo ufw default deny incoming
sudo ufw default allow outgoing

# 允许 SSH（重要！先执行这个）
sudo ufw allow ssh
# 或指定端口
sudo ufw allow 22/tcp

# 允许 HTTP/HTTPS
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

# 允许特定 IP 访问
sudo ufw allow from 192.168.1.100 to any port 22

# 允许端口范围
sudo ufw allow 6000:6007/tcp

# 查看状态
sudo ufw status verbose

# 删除规则
sudo ufw delete allow 80/tcp

# 重置所有规则
sudo ufw reset
```

#### iptables（高级）

```bash
# 查看当前规则
sudo iptables -L -v -n

# 允许已建立的连接
sudo iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT

# 允许 SSH
sudo iptables -A INPUT -p tcp --dport 22 -j ACCEPT

# 允许 HTTP/HTTPS
sudo iptables -A INPUT -p tcp --dport 80 -j ACCEPT
sudo iptables -A INPUT -p tcp --dport 443 -j ACCEPT

# 保存规则
sudo apt-get install iptables-persistent
sudo netfilter-persistent save
```

### 2.5 安全加固

#### 安装 Fail2Ban

```bash
# 安装
sudo apt-get install fail2ban

# 创建配置文件
sudo cp /etc/fail2ban/jail.conf /etc/fail2ban/jail.local

# 编辑配置
sudo vim /etc/fail2ban/jail.local

# 启用 SSH 保护
[sshd]
enabled = true
port = ssh
filter = sshd
logpath = /var/log/auth.log
maxretry = 5
bantime = 3600

# 启动服务
sudo systemctl start fail2ban
sudo systemctl enable fail2ban

# 查看状态
sudo fail2ban-client status
sudo fail2ban-client status sshd
```

#### 自动安全更新

```bash
# 安装
sudo apt-get install unattended-upgrades

# 配置
sudo dpkg-reconfigure -plow unattended-upgrades

# 编辑配置（可选）
sudo vim /etc/apt/apt.conf.d/50unattended-upgrades
```

#### 配置时间同步（NTP）

```bash
# 安装 chrony
sudo apt-get install chrony

# 启动服务
sudo systemctl start chrony
sudo systemctl enable chrony

# 验证同步状态
chronyc tracking
```

#### 配置日志轮转

```bash
# 创建配置文件
sudo vim /etc/logrotate.d/app

# 添加配置
/opt/app/logs/*.log {
    daily
    rotate 14
    compress
    delaycompress
    notifempty
    create 0644 deploy deploy
    sharedscripts
    postrotate
        systemctl reload myapp
    endscript
}

# 测试配置
sudo logrotate -d /etc/logrotate.d/app

# 强制轮转
sudo logrotate -f /etc/logrotate.conf
```

## 3. 环境变量管理

### 3.1 开发环境

**.env 文件**:

```bash
# .env
DEBUG=True
SECRET_KEY=dev-secret-key-dont-use-in-production
DATABASE_URL=sqlite:///dev.db
REDIS_URL=redis://localhost:6379/0
```

**使用 python-dotenv**:

```python
from dotenv import load_dotenv
import os

load_dotenv()

SECRET_KEY = os.getenv('SECRET_KEY')
```

### 3.2 生产环境

**使用系统环境变量**:

```bash
# 添加到 ~/.bashrc 或 /etc/environment
export SECRET_KEY="production-secret-key"
export DATABASE_URL="postgresql://user:pass@localhost/dbname"
```

**使用 Docker Secrets**:

```yaml
services:
  web:
    environment:
      - SECRET_KEY_FILE=/run/secrets/secret_key
    secrets:
      - secret_key

secrets:
  secret_key:
    file: ./secrets/secret_key.txt
```

### 3.3 使用 dotenv 工具

```bash
# 安装
pip install python-dotenv[cli]

# 运行应用时加载环境变量
dotenv run python app.py

# 列出所有变量
dotenv list

# 设置变量
dotenv set SECRET_KEY "new-secret-key"
```

## 4. 数据库准备

### 4.1 PostgreSQL

```bash
# 安装
sudo apt-get install postgresql postgresql-contrib

# 启动服务
sudo systemctl start postgresql
sudo systemctl enable postgresql

# 切换到 postgres 用户
sudo -u postgres psql

# 创建数据库和用户
CREATE DATABASE myapp;
CREATE USER myapp_user WITH ENCRYPTED PASSWORD 'password';
GRANT ALL PRIVILEGES ON DATABASE myapp TO myapp_user;
\q
```

### 4.2 MySQL

```bash
# 安装
sudo apt-get install mysql-server

# 安全配置
sudo mysql_secure_installation

# 登录
sudo mysql

# 创建数据库
CREATE DATABASE myapp CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'myapp_user'@'localhost' IDENTIFIED BY 'password';
GRANT ALL PRIVILEGES ON myapp.* TO 'myapp_user'@'localhost';
FLUSH PRIVILEGES;
```

### 4.3 Redis

```bash
# 安装
sudo apt-get install redis-server

# 配置
sudo vim /etc/redis/redis.conf

# 设置密码
requirepass your-strong-password

# 重启服务
sudo systemctl restart redis-server

# 测试连接
redis-cli
AUTH your-strong-password
PING
```
